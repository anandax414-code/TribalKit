Access Governance

Four Protocol Tiers

Each data point carries protocol metadata. The AR viewer enforces these rules client-side. Sacred content never even exists in a downloadable form.

Public

Open Sharing

Place names, general history, educational content. Viewable by anyone with the AR app. Attribution always required. AI training always prohibited.

  • Visible to all visitors
  • Attribution required
  • No AI training / extraction
  • Cacheable for 24 hours
Restricted

Acknowledged Access

Cultural sites and sensitive knowledge. Visitors must acknowledge protocols before viewing. Locations shown at reduced precision (~500m).

  • Acknowledgment required
  • Approximate locations only
  • No caching permitted
  • Geofenced to vicinity
Sacred

Warning Zones Only

No content is disclosed. When visitors approach a sacred site, they receive only a respectful warning to tread carefully. No coordinates, no details.

  • Warning text only
  • No content revealed
  • ~1km precision radius
  • Presence-triggered respect notice
Seasonal

Calendar-Governed

Content available only during specific cultural seasons, as determined by the Cultural Committee. Acknowledgment required. No permanent access.

  • Time-gated availability
  • Cultural calendar authority
  • Acknowledgment required
  • Revocable at any time

AI Decoupling

How Content Stays Sovereign

Multiple enforcement layers ensure AR content never feeds global AI models.

robots.txt

Blocks 20+ known AI training crawlers including GPTBot, ClaudeBot, CCBot, Google-Extended, Meta-ExternalAgent, and Bytespider. Updated with each release.

Meta Headers

HTML meta tags signal noai, noimageai, and data-sovereignty: tribal to any crawler that respects content-preference headers.

Protocol Metadata

Every GeoJSON feature carries no_ai_training: true in its properties. This survives any re-hosting or format conversion.

No Raw Sacred Data

Sacred-tier content has no GeoJSON file at all. Warning text is hard-coded in the manifest. There is literally nothing for a crawler to extract.

Client-Side Only

The AR viewer runs entirely in the browser. No server-side API means no endpoint for bots to query. Data lives in static files under your Git history.

Revocable at Any Time

Delete a layer file, push to GitHub. It's gone. No cached API responses, no third-party databases retaining your data. Git is the audit trail.

Ethical Framework

CARE Principles Alignment

This framework is designed to implement the CARE Principles for Indigenous Data Governance at the infrastructure level.

C

Collective Benefit

AR layers serve community education, cultural preservation, and land stewardship — not commercial extraction. Benefits flow to the nation, not platforms.

A

Authority to Control

The tribal repository owner has complete authority. Every layer, every protocol level, every revocation decision is made by the governing body — not a platform admin.

R

Responsibility

Protocol tiers ensure sensitive knowledge is shared responsibly. Sacred content is never exposed. Restricted content requires acknowledgment. All content requires attribution.

E

Ethics

The no-AI-training stance is enforced at every level — robots.txt, meta headers, protocol metadata, and architectural design. Consent is ongoing and revocable.
